# Promptome Plugins

Claude Cowork plugins for solo founders and indie builders.

**Available plugins:**
- **Signal** — daily web scanner scored against your personal lens
- **Company Brain** — persistent company knowledge for Claude

**Install:**
Add this marketplace in Cowork → Customize → Create Plugin → Add Marketplace:
`github.com/rancha997/promptome`
