# /setup-brain

Run the full Company Brain onboarding in one session.

What it does:
1. Detects which platform MCPs you have connected (Notion, Google Drive, Confluence)
2. If multiple connected, asks which one to use — once
3. Searches for an existing Company Brain automatically
4. If found — connects and loads it. No interview needed.
5. If not found — runs the full setup interview and creates both the agent context file and source docs

Usage: /setup-brain
