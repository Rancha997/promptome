# /brain-update

Save something specific to the Company Brain right now.

Use this to manually save a decision, convention, project update,
or rejected idea. Claude will extract the key knowledge from the
current conversation and save it to the right section.

For small things, just tell Claude directly:
"Save this to the brain" — no slash command needed.

Usage: /brain-update
